# CARLA substep 비교 검증 마감 · 2026-09-26

## 결론

기록된 실제 CARLA 결과에서, 같은 준비 요청과 고정 throttle 이후 2초의 가속도
부호 교대는 substep 0.01s의 39/39에서 0.005s의 0/39로 바뀌었다. 가속도
범위는 0.449379에서 0.074947m/s²로 83.322% 감소했다. 이는 해당 조건의
substep 설정 민감성이다. 타이어/solver 중 유일한 원인, 실제 내부 substep 횟수,
실차 모델 정합성 또는 기존 주행 시험 통과를 입증한 결과가 아니다.

이 문서는 여러 작업 폴더의 원본을 experiment ID로 대조한 최종 집계다. 이번 마감에서는
새 시뮬레이션을 실행하지 않았고, 기존 보고서·소스·DB·production 설정을 수정하지 않았다.

실제 설치 빌드에서 설정 API 호출 중 한 frame이 진행됐다. 별도 v2 계약은 F0와 첫
고정 명령 ACK 이후 양쪽 모두 같은 설정 API를 호출하고 그 한 frame을 첫 측정 구간에
포함한다. 나머지 39구간만 명시적으로 tick한다. 대조군에도 같은 API 호출을 적용하므로
설정 호출 유무와 substep 변경을 혼동하지 않는다. v1의 시간·필드·원본은 변경하지 않았다.

## 중복을 제외한 실행 집계

완료된 native substep 진단은 8개 ID이며 각 설정 4개다. 같은 설정의 속도·가속도 열은
동일하므로 독립 확률 표본 4개로 해석하지 않는다. 원본 준비 기준은 두 종류이므로 각각의
기준 capture로 검증했고, 기준이 다른 실행을 하나의 통제된 비교로 합치지 않았다.

별도 commissioning 1건은 준비 기준 실패이며 계측 80명령은 미시도다. 또 다른 요청
1건은 engine lock 획득 전에 거절돼 물리 실행으로 세지 않는다. 이 실패들은 삭제하거나
성공으로 대체하지 않았다. 여러 폴더의 같은 report hash·ID는 복사본으로만 집계했다.

## 이번에 다시 확인한 범위

현재 reader로 완료 8건의 원본 chain·입력·소스·ACK·전체 관측을 검증했다. 9월 14일
v1 PI/고정 throttle 2건도 원래 source bundle로 정상 해석했다. 최신 선택 쌍의 원격
원본 8파일은 로컬 hash와 일치한다.

원격 조회에서 마지막 완료 뒤 world/map/settings/weather와 23actor가 같고,
quarantine은 없으며 worker는 응답한다. 배포 release 92파일 hash가 일치했다.
기존 `.data` 749파일은 비교 snapshot 대비 추가·누락·변경이 모두 0이었다.
DB는 74runs·81jobs·349artifacts·11recordings, quick_check 정상·외래키 오류 0이다.

별도 선택 회귀는 **183개 통과·경고 2개, 64.05초**다. 이전 135/167 등의 검사와
범위가 겹치므로 합산하지 않는다. Chrome의 실제 결과 HTML에서 측정 82행, 준비 452행,
단일 선택 41행, 모두 해제 0행과 페이지 오류 0을 확인했다. 이는 전체 플랫폼 UI 시험이나
주행 품질 인수가 아니다.

## 다음 개발 작업

확인된 substep 조건을 명시적으로 고정하는 별도 실행 버전/설정으로 연결하고 기존
cruise·close-lead를 원래 감속 6m/s²·jerk 10m/s³ 기준으로 재평가한다. 결과가 같다는
이유로 반복 진단을 계속 늘리거나 production 기본값을 조용히 바꾸지 않는다. 기존 실패,
미실행 brake pulse, 완만 정지·실차 정합성·상용 gate는 그대로 남는다.
