# Object Sim · 도심 우회전과 선행차 반응

2026-10-09. `urban_right_turn`은 같은 자차 설정으로 앞차의 정지 행동만 바꿔
Town10HD_Opt 우회전 결과를 비교하는 프리셋이다. 기존 네 프리셋과 저장 결과를 유지한다.

정지 유지 개선 후 원본 RGB A/B 두 실행을 완료하고, B와 비교 대상 A를 다섯 번째 프리셋에
고정했다. 일반 빠른 시작에서 저장 결과·공통 시간 비교·앞차 대기 시간 편집·관측 사건 시연을
사용할 수 있다. 기존 네 프리셋의 고정 입력과 저장 결과는 그대로다.

초기 영상 없는 B 실행은 목표 도달·접촉 기준을 통과했지만 앞차 뒤에서 짧게 멈췄다 전진하는
크리프를 보였다. 이 결과는 `.runtime/object-turn-20261009/rehearsal-analysis.json`에 보존한다.
최종 실행은 관측한 앞차의 속도·간격에 따라 정지를 유지하는 `axiom-reactive-planner/1.1`을
사용했다. 자차에 대기 행동을 추가하지 않았다.

## 화면에서 사용하는 기능

- 빠른 시작의 **도심 우회전 · 앞차 반응**에서 저장된 정지·재출발 장면을 연다.
- **저장 A/B 비교**는 A의 계속 진행과 B의 앞차 정지를 공통 시간축으로 연다.
- **앞차 정지 유지 시간**은 0–6초다. 0초는 앞차의 대기 행동 자체를 제거한다.
  양수는 앞차의 대기 시간만 바꾼다. 자차의 속도·제어·행동 설정은 유지한다.
- 분석 장면은 현재 planner 판단에 기록된 선행 대상을 강조한다. 원본 RGB 위에 추정
  검출 상자를 만들지 않는다. 실제 요청 속도·간격·선행차 속도는 보존된 판단에서 읽는다.
- 전방 RGB 960×540·20Hz와 추적 RGB 960×540·10Hz를 같은 시각에 조사한다.
  이전 검증 프레임 유지 방식과 출처·시각 표시는 기존 깜빡임 수정 동작을 따른다.

## 최종 native A/B 결과

두 실행은 지도·seed·카메라·신호·planner와 자차 설정이 같고, B 앞차의 `lead_wait`만 다르다.
표의 시각은 보존된 응답 프레임의 공통 simulation time이다.

| 항목 | A · 앞차 계속 진행 | B · 앞차 6초 대기 |
| --- | --- | --- |
| 실행 | `job_81baf12c08d34a64a0479a9515e6846a` | `job_b3539a82055046cb9c70bafbf4353eb2` |
| 기존 제한 기준 | pass, 소유 actor 정리 확인 | pass, 소유 actor 정리 확인 |
| 자차 도착 판단 시각 | 13.85초 | 21.45초 |
| 자차 목표 오차 / 횡오차 p95 | 0.965m / 0.498m | 1.009m / 0.500m |
| 자차의 앞차 정지 유지 | 없음 | 6.45–8.90초, 50개 응답 표본 |
| 해당 정지 구간의 실제 최고 속도 | 해당 없음 | 0.000496m/s |
| 관측한 최소 선행 간격 | 7.486m | 3.951m |
| native 차량 접촉 callback | 자차·앞차 모두 기록 없음 | 자차·앞차 모두 기록 없음 |
| 보존 RGB / 보고된 누락 | 720장 / 0 | 720장 / 0 |

B의 정지 해제 요청은 8.95초 응답에 기록되며 당시 관측한 앞차 속도는 0.403m/s다.
자차 실제 속도가 0.2m/s를 넘은 첫 응답은 9.35초다. 명령 전환과 실제 이동을 구분한다.
`object-story-rules/5`는 이 정지·해제 근거와 도착을 원본 시각으로 시연한다.

API 확인에서 0초 미리보기는 저장 A, 6초 미리보기는 저장 B 입력과 일치했고 기존 네 binding은
변경되지 않았다. 관련 backend·adapter·script·SDK 시험은 209개 통과, 의존성 deprecation
경고 2개였다. 실행·hash·API·브라우저 근거는
[검증 인덱스](validation/object-sim-urban-interaction-20261009.json)에 연결한다.

현재 시연에는 **추적 RGB**를 권장한다. 같은 로컬 브라우저의 짧은 A/B 재생에서 추적은
실제 5.026초 동안 원본 4.75초(약 0.945×), 전방은 실제 5.014초 동안 원본 3.40초(약 0.678×)
진행했다. 전방 20Hz는 보존 영상의 표본 간격이며 UI 20fps나 실시간 재생 보장이 아니다.
전방 원본은 조사용으로 유지하며, 고해상도 A/B 재생 성능 개선은 남아 있다.

## 재생 배치와 객체 가림 수정

원본 프레임을 기다릴 때 공통 재생 막대에 문구가 추가되면서 높이가 26px 늘어나는 현상을
수정했다. 상태 영역은 항상 같은 높이를 사용하며 400ms 이상 이어지는 대기만 안내한다.
안내가 표시되면 최소 600ms 유지한다. 이 시간은 안내 문구에만 적용하며 원본 준비 확인,
오류 처리와 재생 시계는 그대로다.

3D 도식 안의 큰 판단 박스·설명·조작 버튼은 도식 아래로 옮겼다. 객체 이름표는 작은 ID만
표시하고 실제 판단 대상의 주황색 윤곽선은 유지한다. 현재 판단·요청 속도·대상 간격은
높이 82px의 정보 영역에 표시하며, 관측 시각·입력 frame·표시 옵션은 **판단·표시 상세**에서
확인한다. 상세 내용을 펼쳐도 해당 영역 안에서 스크롤하여 객체 영역 높이를 바꾸지 않는다.

로컬 브라우저의 수정 전 216개 표본에서 재생 막대 높이가 60/86px로 바뀌었다.
수정 후 재생 344개 표본과 일반 1102px 창의 정지·재출발 277개 표본에서는 각각 높이와
하단 패널 위치가 고정됐다. 관련 frontend 시험 28개와 production build를 확인했다.
저장된 CARLA 결과를 재생한 UI 확인이며 새 native 실행은 없다.
[화면·측정 근거](validation/object-sim-layout-20261009.json).

## 고정 입력과 API

| 항목 | 설정 |
| --- | --- |
| 지도·경로 | 고정 Town10HD_Opt 개정, 기존 우회전 경로의 native directed edge 23개 경로점 |
| 차량 | 자차·앞차 모두 동일 reactive planner, 목표 속도 각 4m/s |
| 초기 간격 | 경로를 따라 약 12m, 앞차 목적지는 자차 목적지보다 약 20m 앞 |
| A | 앞차의 별도 대기 행동 없음 |
| B | 앞차 `lead_wait`: 2초 명령 시각에 시작, 정지한 뒤 6초 유지 |
| 자차 | 두 실행 모두 작성한 정지·대기 행동 없음 |
| 교통 신호 | 등록된 native 신호를 녹색으로 고정해 선행차 반응을 분리 |
| 시간·카메라 | 24초, physics 20Hz, 전방480장·추적240장 = 실행당720장 |
| 원본 예산 | 실행당 BGRA 1,492,992,000바이트, adapter 허용치2,013,265,920바이트 이내 |

기존 `object-sim-presets/1`·`object-sim-preview/1`·`object-sim-comparison/1` API를 쓴다.
새 binding의 `actor_roles`는 `ego`·`lead`, 편집 파라미터는 `lead_wait_s`다.
`saved_execution_id`에는 B, 선택 필드 `saved_comparison_execution_id`에는 A를 고정한다.
두 실행은 같은 프로젝트의 완료된 호환 결과여야 하며, 이 프리셋의 저장 A는 저장 B에서
앞차의 대기 행동만 제거한 입력이어야 한다. 기존 binding의 manifest를 다시 쓰지 않는다.
Python SDK도 동일한 필드와 범위 검사를 제공한다.

[작성·실행 스크립트](../scripts/object_sim_urban_interaction.py)는 일반 프로젝트 API를 통해
source scenario와 native map을 고정하고 A/B를 각각 작성한다. `author`, `run`, `publish`를
분리하며 같은 receipt를 사용한 재개는 기존 job을 재사용한다. `--camera-free --side B`는
영상 없는 행동 확인에 사용하며 프리셋으로 발행할 수 없다. native 경로점이 겹치는 교차로에서도
실제 directed edge 연결을 따르며 임의 XY 재배치나 차량 순간이동을 사용하지 않는다.

## 해석 범위

지도와 객체 GT를 입력받는 규칙 기반 제어 및 CARLA 원본 렌더 영상이다. RGB 인지 모델,
실차 안전성, 센서 물리 정합이나 도시 전체 주행 능력의 검증이 아니다. 신호를 녹색으로
고정했으므로 비보호 좌회전·신호 우선권 협상 결과로 해석하지 않는다.
